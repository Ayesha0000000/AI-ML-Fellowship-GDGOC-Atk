Week 5 - Machine Learning and Model Evaluation
Introduction

In this week, we learned the basics of Machine Learning and how to build simple models. We also studied how to evaluate model performance using different evaluation metrics. The main focus was on Logistic Regression and understanding how models perform on data.

Learning Objectives

The main objectives of this week were to understand machine learning concepts, learn how models are trained, and evaluate their performance using proper techniques.

Topics Covered

Introduction to Machine Learning
We learned what machine learning is and how it helps systems learn from data and make predictions.

Logistic Regression
We studied Logistic Regression as a classification algorithm and implemented it from scratch to understand how it works.

Data Preprocessing
We cleaned and prepared the dataset before training the model. This included handling missing values and organizing data.

Model Evaluation Metrics
We learned different methods to evaluate models such as accuracy, precision, recall, and F1-score. We also studied regression metrics like MAE, MSE, RMSE, and R-squared

Confusion Matrix
We understood how confusion matrix helps in evaluating classification models using true positive, true negative, false positive, and false negative values.

Overfitting and Underfitting
We studied how models can perform poorly if they are too simple or too complex, and how to handle these problems.

Bias and Variance
We learned the difference between bias and variance and how to balance them for better model performance.

Practice Work

In this week, we implemented machine learning models, worked on Logistic Regression from scratch, and evaluated model performance using different metrics.

Conclusion

This week helped us understand how machine learning models are built and evaluated. We learned the importance of proper evaluation techniques to ensure that models perform well on new data.
