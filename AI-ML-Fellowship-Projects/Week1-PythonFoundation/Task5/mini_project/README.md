# 📝 Daily Journal – Streamlit Mini Project (Task 5)

This project is developed as part of **AI/ML Fellowship – Week 1 (Python Foundation)**.

A simple **Daily Journal web application** built using **Python and Streamlit** where users can write daily thoughts, select their mood, and view previous journal entries.

---

## 🚀 Features
- Write daily journal entries
- Select mood (Happy, Neutral, Tired, Stressed)
- Save entries with date & time
- View previous entries
- Simple and clean UI
- Data stored locally in JSON format

---

## 🛠 Tech Stack
- Python
- Streamlit
- JSON

---

## ▶️ How to Run the App

```bash
pip install -r requirements.txt
python -m streamlit run src/app.py
