Week 1 - Python Basics
Introduction

In this week, we learned the basic concepts of Python programming. Python is a simple and easy-to-learn language used in many fields such as web development, artificial intelligence, and data analysis.

Learning Objectives

The main objectives of this week were to understand Python syntax, learn how to use variables and data types, take input from the user, and display output.

Topics Covered

Python Introduction
We learned what Python is and how to write and run a basic program.

Variables
We learned how to store data in variables.

Data Types
We studied different types of data such as string, integer, float, and boolean.

Input and Output
We learned how to take input from the user and display results.

Operators
We performed basic arithmetic operations like addition, subtraction, multiplication, and division.

Conditional Statements
We learned how to make decisions in programs using conditions.

Loops
We used loops to repeat tasks multiple times.

Practice Work

In this week, we created simple programs such as a calculator, even/odd checker, and table generator.

Conclusion

This week helped us build a strong foundation in Python. We are now able to write basic programs and understand core programming concepts.
